Introduction

Tester Present, service identifier 0x3E, indicates that a diagnostic client is still present and intends to continue diagnostic communication. It does not read data, execute routines, transfer software, or grant permissions.

Key concept: Tester Present helps maintain an already established diagnostic session. It does not create or restore Programming Session.

Diagnostic sessions

A client uses Diagnostic Session Control, SID 0x10, to request a session. Common standardized session values include:

10 01 Default Session 10 02 Programming Session 10 03 Extended Diagnostic Session

For a non-default session, the server's session management may require continued diagnostic communication. If the applicable inactivity condition is reached, the server may return to Default Session. Exact timing and implementation behavior are system-specific.

Tester Present request and response

Positive response requested

UDS request: 3E 00 UDS response: 7E 00

The response SID is 0x3E + 0x40. Transport bytes, such as ISO-TP PCI, are intentionally excluded.

Positive response suppressed

UDS request: 3E 80

Bit 7 is the suppress-positive-response-message-indication bit. A valid request asks the server not to send a positive response. Applicable negative-response behavior remains governed by the protocol and implementation.

Important: Seeing 3E 80 on a transmit trace proves transmission by the client. It does not, by itself, prove reception, acceptance, or continued session state at the server.

Verification strategy

A trace-based test should distinguish transmission evidence from server-state evidence. If the ECU supports a session-state DID such as F186 in the target diagnostic specification, a project-specific check may look like:

10 02 Request Programming Session 50 02 Positive response 22 F1 86 Project-specific read request 62 F1 86 Project-specific read response 3E 80 Tester Present, positive response suppressed 22 F1 86 Read again 62 F1 86 Confirm reported session state

F186 usage and data encoding must be confirmed in the ECU's diagnostic specification. It should not be presented as universally supported by every UDS server.
